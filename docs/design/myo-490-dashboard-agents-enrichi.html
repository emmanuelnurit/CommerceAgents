B — Bloc « Agents IA » (carte inchangée + 1 signal ajouté) file unifiée

La carte garde exactement ce que MYO-294 a dégraissé : nom, statut métier, 1 dernière action, 1 prochaine échéance, les 3 raccourcis (historique / configurer / lancer). Le seul ajout est un badge « N à valider », qui fusionne agent_staged_change en attente et agent_outbound_message en attente pour cet agent — voir l'argumentaire « deux files ou une » dans le commentaire de synthèse. Le badge est absent quand N = 0 (pas de "0" affiché, cf. MYO-482 §1.1). Le coût par agent n'est pas sur la carte — il est one tap plus loin, sur la page agent (section D), pour ne pas raviver le fourre-tout que MYO-294 a corrigé.
